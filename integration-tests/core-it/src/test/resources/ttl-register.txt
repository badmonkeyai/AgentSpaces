# The TTL register (srad/agentspaces-event-loop.md §3.11, EL-E-01, EL-E-02, EL-E-09).
#
# Every default TTL, lease and expiry of the core, one per line:
#
#   <class>#<member> <value> [reason]
#
# <member> is a static field (FIELD), an annotation member's default (member()), or a getter chain on a new instance
# (getA().getB()). <value> is a duration (250ms, 30s, 15m, 1h, 7d, or ISO-8601) or, for a count, a plain integer.
# A long field or getter whose name ends in MILLIS is read as milliseconds. A duration under 60 s carries its reason:
# principle 8, "a TTL under 60 s is probably too fast, unless someone really knows what they are doing"; the reason is
# that someone. TtlRegisterTest (core-it) reads every line by reflection and fails on a value that differs from the
# code, on a duration under 60 s with no reason, on a line that matches no code, and on a lease or TTL member of the
# binder's annotations that is missing here.
